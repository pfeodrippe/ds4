Evaluate the integral of x^2 from 0 to 1. Let me work through this step by step. The integral of x^2 is x^3/3. Evaluating at the bounds: (1^3/3) - (0^3/3) = 1/3 - 0 = 1/3.

Find the derivative of sin(x^2). Using the chain rule: d/dx[sin(u)] = cos(u) * du/dx where u = x^2. So du/dx = 2x. Therefore the derivative is 2x*cos(x^2).

Solve the differential equation dy/dx = y. This is separable: dy/y = dx. Integrating both sides: ln|y| = x + C. Exponentiating: y = Ce^x.

Compute the limit as x approaches 0 of sin(x)/x. Using L'Hopital's rule: lim sin(x)/x = lim cos(x)/1 = cos(0)/1 = 1.

Find the Taylor series of e^x around 0. The nth derivative of e^x at 0 is 1 for all n. So the Taylor series is sum_{n=0}^infty x^n/n! = 1 + x + x^2/2! + x^3/3! + ...

Solve x^2 - 5x + 6 = 0. Factoring: (x-2)(x-3) = 0. Therefore x = 2 or x = 3.

Find the roots of x^3 - 6x^2 + 11x - 6 = 0. Trying x=1: 1-6+11-6=0, so (x-1) is a factor. Polynomial division gives (x-1)(x^2-5x+6) = (x-1)(x-2)(x-3). Roots: 1, 2, 3.

Simplify (a^2 - b^2)/(a - b). The numerator factors as (a-b)(a+b). Canceling (a-b): result is a + b, for a ≠ b.

Find gcd(48, 18). Using Euclidean algorithm: 48 = 2*18 + 12, 18 = 1*12 + 6, 12 = 2*6 + 0. So gcd(48, 18) = 6.

Prove there are infinitely many primes. Suppose there are finitely many primes p1,...,pn. Consider N = p1*p2*...*pn + 1. N is not divisible by any pi, so either N is prime or has a prime factor not in our list. Contradiction.

Find the determinant of [[1,2],[3,4]]. det = 1*4 - 2*3 = 4 - 6 = -2.

Find eigenvalues of [[2,1],[1,2]]. Characteristic polynomial: det(A-λI) = (2-λ)^2 - 1 = λ^2 - 4λ + 3 = (λ-1)(λ-3). Eigenvalues: 1 and 3.

A fair die is rolled. What's P(at least 4)? Favorable outcomes: {4,5,6}. Total: 6. P = 3/6 = 1/2.

Two cards drawn without replacement from a 52-card deck. P(both aces) = (4/52)*(3/51) = 12/2652 = 1/221.

Find the area of a circle with radius 3. A = πr^2 = π*9 = 9π.

Find the distance between (1,2) and (4,6). d = sqrt((4-1)^2 + (6-2)^2) = sqrt(9 + 16) = sqrt(25) = 5.

How many ways to choose 3 people from 10? C(10,3) = 10!/(3!*7!) = (10*9*8)/(3*2*1) = 120.

How many permutations of {1,2,3,4}? 4! = 24.

Sum of first n natural numbers: S = n(n+1)/2. Proof by induction: Base n=1: 1 = 1*2/2 = 1 ✓. Assume for n, then S_{n+1} = n(n+1)/2 + (n+1) = (n+1)(n+2)/2.

Does sum 1/n^2 converge? Yes, by p-test with p=2 > 1. The sum equals π^2/6 (Basel problem).

Prove sqrt(2) is irrational. Suppose sqrt(2) = p/q in lowest terms. Then 2q^2 = p^2, so p^2 is even, thus p is even. Let p=2k. Then 2q^2 = 4k^2, so q^2 = 2k^2, thus q is even. But then p,q both even, contradiction.

Compute (1+i)^2. (1+i)^2 = 1 + 2i + i^2 = 1 + 2i - 1 = 2i.

Find |3+4i|. |3+4i| = sqrt(3^2 + 4^2) = sqrt(9+16) = sqrt(25) = 5.

Prove sin^2(x) + cos^2(x) = 1. From the unit circle: point (cos x, sin x) has distance 1 from origin. So cos^2(x) + sin^2(x) = 1^2 = 1.

Find sin(π/6). In a 30-60-90 triangle, sides are 1 : sqrt(3) : 2. sin(30°) = opposite/hypotenuse = 1/2.

Find the maximum of f(x) = -x^2 + 4x. f'(x) = -2x + 4 = 0 → x = 2. f''(x) = -2 < 0, so x=2 is a maximum. f(2) = -4 + 8 = 4.

Prove A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C). Let x ∈ LHS. Then x ∈ A or x ∈ B ∩ C. If x ∈ A, then x ∈ A ∪ B and x ∈ A ∪ C. If x ∈ B ∩ C, then x ∈ B and x ∈ C, so x ∈ A ∪ B and x ∈ A ∪ C. Thus x ∈ RHS. Reverse inclusion is similar.

Show that (Z, +) is a group. Closure: a+b ∈ Z. Associativity: (a+b)+c = a+(b+c). Identity: 0, since a+0 = a. Inverse: -a, since a+(-a) = 0.

In a complete graph K_n, how many edges? Each vertex connects to n-1 others. Total vertex-edge incidences: n(n-1). Each edge counted twice. So edges = n(n-1)/2.

Prove a tree with n vertices has n-1 edges. By induction: Base n=1: 0 edges. For n>1, a tree has a leaf. Remove it and its edge. The remaining tree has n-1 vertices, so n-2 edges by IH. Add back the leaf: n-1 edges.

Solve y'' + y = 0. Characteristic equation: r^2 + 1 = 0, so r = ±i. General solution: y = C1*cos(x) + C2*sin(x).

Approximate sqrt(2) using Newton's method. f(x) = x^2 - 2, f'(x) = 2x. x_{n+1} = x_n - (x_n^2-2)/(2x_n) = (x_n + 2/x_n)/2. Starting with x_0=1: x_1=1.5, x_2=1.4167, x_3=1.4142...

Prove e is irrational. Suppose e = p/q. Then q!*e = q!*(1 + 1 + 1/2! + ... + 1/q! + R) where 0 < R < 1/q!. The first q+1 terms give an integer, but q!*R is not an integer. Contradiction.

Prove [0,1] is compact. Let {U_i} be an open cover. Since [0,1] is closed and bounded in R, by Heine-Borel it is compact.

In a field, prove 0*a = 0 for all a. 0*a = (0+0)*a = 0*a + 0*a. Subtracting 0*a from both sides: 0 = 0*a.
